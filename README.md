## Basic-Calculator
Basic GUI Calculator / Java Swing

## Features
- Multiply, Add, Subtract, Divide
- Bracket Functionality


## Technologies Used
- Java Swing, AWT

## My Strategy
For this calculator i decided to get all inputs as a string, then convert the string to two arrays: one with the numbers, another with the operators. The arrays are ordered so that the operations line up in BIDMAS order and caclulations are broken up so that the result of one feeds into the next. once all calculations are performed the number array has only the result remaining, which is then displayed in the GUI.
