## Basic-Calculator
Basic GUI Calculator / Java Swing

## Features
- Multiply, Add, Subtract, Divide
- Bracket Functionality


## Technologies Used
- Java Swing, AWT

## My Strategy
For this calculator i decided to get all inputs as a string, then convert the string to two arrays: one with the numbers, another with the operators. The arrays are ordered so that the operations line up in BIDMAS order and caclulations are broken up so that the result of one feeds into the next. once all calculations are performed the number array has only the result remaining, which is then displayed in the GUI. 

## What I Learned
- This project really helped my understanding of tackling new problems.
- Everytime I solved one issue with the string conversion, another seemed to arise.
- For this project I did not initially map out all of the different scenarios for which I'd need to convert the string to a series of operations, I went in straight forward and fixed each problem as it arised.
- Later down the line, I shifted my approach by mapping out on a notepad all possible variations of inputs that could create an issue with my current logic design.
- This allowed me to more efficiently tackle each problem, instead of going in blind and stumbling upon new ones.
-  This project taught me the importance of planning and designing before actually implementing solutions.
-  Since working on this, the projects I am currently working on have been much less troublesome as I have more thoroughly planned how I am going to tackle each area of the problems that I face.
